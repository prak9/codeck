# 历史搜索与成果证据

普通模式和 Remote 侧栏提供“搜索历史内容”；可打开原始上下文，核验并关联本地 Git 提交。发布页通过“版本与验证”展示当前成果的检查记录和未验证范围。

Agent 使用 `codeck history search/context/link`；发布时用 `codeck page publish ... --evidence RECORD.json`。

[完整使用说明与数据边界](../skills/codeck/references/history-evidence.md)包含 CLI 示例、索引更新与权限规则、Git 关联含义和证据 JSON 格式。
